# Документация: админские сообщения (messages_admin.py)

Краткая документация по файлу `messages_admin.py` и новым константам, добавленным в ходе рефакторинга.

Цель
- Централизовать все тексты, используемые в режиме администратора, в одном модуле `messages_admin.py`.
- Обеспечить простоту правок, нумерацию сообщений для трассировки и подготовить базу для локализации.

Где находится
- `d:\Python\MyBot\messages_admin.py` — основной файл с константами (все админские тексты).

Новые константы (итерация завершённая 16.11.2025)
- #1.61 FILTER_INVALID_FIELD — сообщение при некорректном выборе поля фильтрации
- #1.62 RETURN_MENU_INVALID_CHOICE — ответ при неверном выборе в меню возврата после сортировки
- #1.63 CONFIRM_YES_NO — шаблон подтверждения (1/2) для удаления/действий
- #1.64 REPEAT_OR_EXIT_PROMPT — шаблон «повторить/выйти» (1/2)
- #1.65 SELECTED_RECORD_TEMPLATE — форматируемый шаблон для выбраной записи
- #1.66 FOUND_RECORD_TEMPLATE — форматируемый шаблон для найденной записи (зарезервирован)

Где используются (ключевые файлы)
- `db/sort_and_filtr.py` — использует FILTER_INVALID_FIELD, RETURN_MENU_INVALID_CHOICE и другие шаблоны пагинации/ошибок из `messages_admin.py`.
- `db/del_record.py` — использует CONFIRM_YES_NO, REPEAT_OR_EXIT_PROMPT, SEARCH_REPEAT_EXIT и т.д.
- `db/edit_db.py` — использует SELECTED_RECORD_TEMPLATE, FIELD_CURRENT_PROMPT, ENTER_NEW_VALUE_PROMPT и пр.
- `db/add_record.py` — использует ENTER_FIELD_TEMPLATE, ADD_SUCCESS_HEADER, ADD_SUMMARY_HEADER, ADD_CONTINUE_PROMPT.
- `db/work_db.py` — использует USER_LIST_HEADER, PAGE_INFO, MEMBER_DETAILS_HEADER, MEMBER_DETAILS_ACTION_PROMPT и пр.
- `db/search_records.py` — использует SEARCH_ENTER_SURNAME, SEARCH_NO_MATCH_*, SEARCH_RESULTS_PROMPT.
- `bot.py` — часть админских меню/drop-down использует константы заголовков и подсказок.

Рекомендации по добавлению/нумерации новых сообщений
1. Всегда открывайте `messages_admin.py` и находите последний номер в формате `(#1.xxx)`.
2. Добавляйте новую константу с следующей свободной нумерацией, давая краткое английское имя константы и русское содержание.
   Пример:
   NEW_MESSAGE = "(#1.67) Текст нового сообщения"
3. Используйте форматированные шаблоны для строк, в которые подставляются переменные, например:
   FIELD_CURRENT_PROMPT = "(#1.16) Текущее значение поля \"{field_name}\": {display}\nВведите новое значение:"
   и подставляйте через `.format(...)`.
4. После правки запустите синтаксическую проверку (см. ниже).

Тест и быстрая проверка
- Быстрая проверка синтаксиса всех Python-файлов:

```powershell
python -m compileall .
```

- Запуск бота (локально) — зависит от вашей конфигурации и токена. Обычно:

```powershell
# Установите зависимости (если ещё не установлены)
python -m pip install -r requirements.txt
# Затем запустите бота
python bot.py
```

Smoke-test (проверьте вручную в Telegram):
- Войти в режим администратора (как настроено в боте).
- Проверить: Показать список, Пагинация, Выбор записи, Редактирование, Удаление, Добавление.
- Убедиться, что сообщения отображаются из `messages_admin.py` и что старые admin-сообщения удаляются корректно.
